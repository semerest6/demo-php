# Common Workflow

## New task
1. Resolve the intended project.
2. Load common and project-specific rules.
3. Restore only relevant project context.
4. Inspect real repository/runtime state.
5. Define the smallest complete user-visible acceptance.
6. Implement the full path.
7. Run proportional validation.
8. Update current documentation and project memory when required.
9. Report the verified result.

## New AI session
Read bootstrap, project-specific rules, current project state if present, relevant product/architecture docs, latest relevant history, then actual code/config and Git state. Do not reload all historical material by default.

## User effort
The user's effort should focus on goals, priorities, taste, approvals and validation only they can provide. Routine repository inspection, implementation, testing and documentation should be performed by AI/tooling when available.
