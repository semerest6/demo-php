# AI bootstrap

This project uses the shared workflow from `semerest6/ai-workflow-core`.

1. Read all files in `.ai/core/`.
2. Read `.ai/PROJECT_RULES.md`.
3. Read the latest relevant `ai-docs/SESSION_LOG.md`.
4. Read only task-relevant project files.
5. Inspect actual Git/code/runtime state before claiming it is verified.

`.ai/core/**` is centrally managed and must not be edited locally. Project rules and project history remain owned by this repository.
